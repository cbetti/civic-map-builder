# Code of Conduct

Be respectful, constructive, and patient. This project welcomes contributions
from people with different levels of civic, mapping, and software experience.

Do not harass, insult, threaten, or deliberately exclude others. Assume good
intent, but accept correction when a maintainer asks for a change in tone or
behavior.

Report concerns privately to the project maintainer. Maintainers may edit,
close, or remove issues, pull requests, comments, or contributions that make the
project harder to participate in.
